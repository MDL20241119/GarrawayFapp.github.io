## 公開情報の範囲
2026年9月9日に取得・照合したスナップショットです。127件（61イベント・66個別セッション）を収録。複数日開催は日程ごとに表示します。47施設・会場のほか、会場未確定などのプレースホルダーが4件あります。未公表の企画を含む完全性やリアルタイム同期を保証するものではありません。出典URLは catalog.js の各レコードに収録しています。

## 非公式表記
マスコットのそばに「非公式キャラ」、ページには非公式ガイドと表示しています。RAMEN TECH事務局の公認・公式キャラクターではありません。

## ファイル
- index.html: ページ構造、検索フォーム、参加案内
- style.css: Bold Mascot の基本デザイン
- search.css: スマホ・一覧・検索の読みやすさ
- app.js: 複合検索、表示、マイ予定、共有、ICS
- catalog.js: 出典と更新日を持つ公開イベントデータ
- assets/tonkotsu.svg: とんこつラーメンの非公式キャラ

ビルド不要の静的サイトです。既存のGarraway Fホームページとは独立したディレクトリに配信しています。

## 検索と予定
全角・半角、英字大小、ひらがな・カタカナを正規化。空白区切りはAND検索。日付、会場、テーマ、時間帯、エリア、参加条件、開始・終了時刻を組み合わせて絞れます。無料・予約不要は明記されている予定のみを対象とし、不明な条件を推定しません。

マイ予定は同一端末・ブラウザのlocalStorageに保存し、サーバーへ送信しません。保存不可の場合は画面内だけ保持して通知します。複数日開催のイベントを保存すると全開催日が対象です。時間重複の表示は移動時間の可否や同一会場での同時開催を保証しません。時刻不明・矛盾のある予定はカレンダー出力から除外します。

## 更新と検証
主催者の一次情報で日付・時刻・場所・参加条件を確認し、catalog.jsのレコードとmeta.checkedAtを更新してください。コードを更新するときはindex.htmlの資産URLのv値も変更してください。

ramen-guide-check.yml は変更時に公開HTTPSページと配信資産を確認し、Chromiumで検索・マイ予定・詳細・ICS・320/390/768/1440px表示を検査します。結果と画面はGitHub Actionsのartifactを参照してください。

mainはGitHub Pagesの配信ファイルです。ホーム全体をsites-source等から再配置するときも、ramen-tech-2026/を保持してください。

data/catalog-*.b64 と ramen-install-catalog.yml は初期公開時にデータを整合性検証して反映するための保存用スナップショットです。通常の更新に再実行は不要です。再実行するとcatalog.jsを2026年9月9日のスナップショットに戻します。
