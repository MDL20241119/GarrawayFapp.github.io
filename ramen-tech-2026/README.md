# RAMEN TECH 2026 / 非公式イベントガイド

公開先: https://mobilitydlab.com/GarrawayFapp.github.io/ramen-tech-2026/

## 毎朝の自動更新

`.github/workflows/ramen-daily-update.yml` を main ブランチで実行します。

- 毎朝 **6:00（日本時間）** に公開データの取得を開始（UTC 21:00）。
- **6:35** は同日の取得・公開が成功していない場合のみ再試行。
- 取得、整合性検証、ブラウザ検査、差分コミット、GitHub Pagesビルド、公開HTTPSページ検査を実行。
- GitHub Actionsの混雑により実行・配信は遅れる場合があります。正確な6時の配信を保証するものではありません。
- Actions画面の `Daily RAMEN event refresh` → `Run workflow` で手動再実行できます。

### 自動取得の対象

1. 公式登録サイト https://members.ramentech.jp/ の公開イベントデータ。
2. 公式時間割 https://ramentech2026.aishain.com/api/schedule の公開セッション・会場データ。

対象は2026年9〜11月のRAMEN TECH関連情報です。全世界の告知サイト・SNSを巡回するものではありません。個別主催者サイト由来の補足、Garraway Fの独自企画は自動上書きしません。補足に関係する登録変更は「要確認」とします。未公表企画を含む完全性を保証しません。

### 更新表示と安全策

`sync-status.json` に実際の実行時刻、最終成功時刻、ソース別成否、件数と変更内容を保存。ページ上部で確認できます。取得失敗・異常な件数減少・形式変更があれば、該当ソースの前回データを保持し、成功したふりをせず警告します。失敗が続いて最終成功から30時間を超えた場合も警告します。

新規イベント・会場は安定したIDで追加し、日時・場所・中止表記などの変更を反映。掲載が消えただけでは中止と決めつけず、前回情報を「要確認」で残します。時刻が食い違う、または中止表記の予定はカレンダー出力を停止します。閲覧中のページより新しいデータがある場合は、手動で読み込むボタンを表示します。

登録・時間割の自動取得時刻 (`autoCheckedAt`) と、人が補足確認した日 (`checkedAt`) は別項目です。古い補足を今日確認したようには扱いません。個別の自動確認警告を解消する際は、一次情報を確認して内容と `checkedAt` を更新し、必要に応じて `sync.needsEditorialReview` を解除します。

## 掲載と検索

初期版は127件（61イベント・66個別セッション）、47施設・会場。現在の件数は `catalog.js` から算出します。複数日開催は日程ごとに表示し、会場未確定のプレースホルダーは施設数から除きます。各レコードに出典URLを収録。

全角・半角、英字大小、ひらがな・カタカナを正規化し、空白区切りはAND検索。日付、会場、テーマ、時間帯、エリア、参加条件、開始・終了時刻を組み合わせて絞れます。無料・予約不要は明記された予定のみです。

マイ予定は同じ端末・ブラウザのlocalStorageに保存し、サーバーには送りません。安定したイベントIDを維持するためデータ更新後も保存を引き継ぎます。端末の保存消去・別ブラウザは対象外です。Googleカレンダー・ICSへ書き出した予定は自動同期されません。更新後は利用者自身で再確認・変更してください。

## 非公式表記

マスコットには「非公式キャラ」、サイトには非公式ガイドと明記。RAMEN TECH事務局の公認・公式キャラクターではありません。

## ファイルと保守

- `index.html` / `style.css` / `search.css` / `app.js`: ページ、Bold Mascotデザイン、検索・保存・共有。
- `catalog.js`: 出典と確認日を持つイベントデータ。
- `assets/tonkotsu.svg`: とんこつラーメンの非公式キャラ。
- `auto-update.js` / `auto-update.css` / `sync-status.*`: 自動更新の状況表示。
- `tools/ramen_sync.py`: 公開ソースの解析・照合・安全な差分更新。
- `tools/test_ramen_sync.py`: 新規追加、変更、中止、掲載消失、障害時の保持などの単体試験。
- `tools/ramen_verify_daily.py`: 公開ファイル、検索、保存、320/390/768/1440px表示の検証。

編集用コードはUTF-8の通常ファイルです。`data/daily-bootstrap-*.b64` は初期導入にのみ使う、SHA-256検証付きの保存用パッケージ。`tools/ramen_sync.py` が存在する場合は展開せず、保守したソースを使います。

従来の `data/catalog-*.b64` と `ramen-install-catalog.yml` は2026年9月9日の初期データです。再実行すると初期スナップショットへ戻るため、通常の更新には使用しないでください。

mainはGitHub Pagesの配信ブランチです。既存ホームページは変更せず専用ディレクトリだけ更新します。ホーム全体をsites-source等から再配置する際も `ramen-tech-2026/` と更新用 tools・workflow を保持してください。
