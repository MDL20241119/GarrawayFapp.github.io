# 九州の秋 2026

オリジナルのAI生成イメージを使い、RAMEN TECHの前後に立ち寄れるイベントを紹介する静的ページ。公開先は `https://garrawayf.github.io/ramen-tech-2026/kyushu/`。親ページの `classic-ui.js` がメニューと特集バナーを追加し、`kyushu-entry.css` を読み込む。

## 掲載範囲と情報更新

- 2026年9月21日〜10月21日に会期が重なる19件を編集部が選定。RAMEN TECH本会期10月7〜11日の前後10日と、関連企画に合わせた先行期間を含む。網羅的なイベントデータベースではない。
- 日程・会場・参加条件の確認日は2026年9月11日。Fukuoka Nowの秋ガイドを企画選びの参考とし、可能な限り2026年の主催者情報を優先した。
- `events.json` に開催日、エリア、紹介文、アクセス、開催情報の出典名・URL・区分・確認日、画像の生成情報を保持する。日付の自動更新や未発表情報の推定は行わない。
- クリエイターズは主催者発表の10月10〜12日を採用。満席の建築見学、詳細発表待ちのオクトーバーフェストは状態を明示。中止が発表された2026年のやつしろ全国花火競技大会は掲載しない。
- 複数県にまたがるツール・ド・九州は `areaDates` で県ごとの開催日も絞り込む。FAN WEEKなどの包括企画は個別会期・休館日の確認が必要なことを明示する。

## 生成と確認

```sh
python3 ramen-tech-2026/kyushu/build-page.py
node --check ramen-tech-2026/kyushu/kyushu.js
python3 ramen-tech-2026/tests/kyushu-compliance.test.py
```

`build-page.py` は同じディレクトリのJSONを読み、画像ファイルと期間の整合性を確認し、カードと構造化された詳細データを含む `index.html` を生成する。JavaScript無効時もカードから開催案内へ進める。JavaScript有効時はエリア・期間・種類の絞り込みと詳細ダイアログを提供する。既存のマイ予定の保存データは変更しない。

公開リポジトリの既存GitHub Actionsがこのディレクトリをコピーし、ページを再生成してから公開する。本文を変更する際はJSONと生成HTMLの両方を更新する。キャッシュ更新用の版番号はページ生成コード、CSS/JS参照、親ページの入口、公開workflowで揃える。

## 画像と情報出典（2026-09-12更新）

旧バージョンで使用した外部サイト由来の写真・告知ビジュアル19ファイルは公開対象から除外した。現在の `images/` は、本特集向けに新規生成した6種類のテーマ別イメージのみ。各イベントと親ページのバナーがこの画像を参照する。生成にはOpenAI内蔵のimage_genを使用し、外部写真・ロゴ・実在人物の画像を入力していない。生成プロンプト、テーマとイベントの対応、ファイル名は `image-manifest.json` に記録する。WebPへの変換は配信用の形式変換のみ。

画像の近くに「AI生成イメージ」「実際のイベント写真ではありません」と明記する。実際の会場・出演者・作品・商品・景観や当日の様子を再現・保証するものではない。AI生成であることをもって権利非侵害や独占的権利を保証するものではなく、追加する画像も第三者の写真・ロゴ・作品の再現を避けて個別に確認する。

情報の出典は画像の説明と分離する。Fukuoka Now「福岡秋のガイド2026」への参照はページ上部と編集方針に常時表示する。カード・詳細・出典一覧に掲載元の名前とリンクを明記し、主催者公式情報／メディア／観光情報を区別する。参照先との提携・公認を示す表現を使わない。

開催情報の確認日は2026-09-11。2026-09-12は画像・表示の更新日であり、日程や料金の再確認日ではない。過去に作成したSNS紹介画像はこの更新で自動的に置換されないため、旧写真を含む画像を再利用しない。

ビルド時は画像マニフェストと実ファイルの完全一致、生成情報、外部画像URLの不在を検証する。Git履歴は保全しており、過去の写真を含む旧版が履歴から復元可能であることと、現行公開ファイルから除外していることは区別する。
